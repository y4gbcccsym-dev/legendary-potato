# AGENTS.md

แนวทางการพัฒนาโปรเจกต์นี้:

- โปรเจกต์นี้ใช้สำหรับนำเข้า/ส่งออกโปรไฟล์ NVIDIA แบบปลอดภัยผ่าน NVIDIA Profile Inspector เท่านั้น
- ห้ามเพิ่มการปรับแต่งระบบที่เสี่ยงหรือทำลายเสถียรภาพของเครื่อง
- ห้ามเพิ่มฟังก์ชันปิดบริการ Windows หรือบริการความปลอดภัยต่าง ๆ
- ห้ามเพิ่มทวีครีจิสทรีสุ่มเพื่อเร่ง FPS
- ข้อความที่ผู้ใช้เห็นควรเป็นภาษาไทยทั้งหมด
- เขียน PowerShell ให้อ่านง่าย พร้อมคอมเมนต์ที่จำเป็น
- ฟังก์ชันที่เสี่ยงต้องเป็น opt-in เท่านั้น และปิดใช้งานเป็นค่าเริ่มต้น
